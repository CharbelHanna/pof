# Point of Focus — user guide

Point of Focus is for **preparing** photoshoots. Not editing them, not selling
them — planning them, so that when the day comes you already know what you are
taking, where you are going, when the light is, and what you are there to get.

This guide is written for photographers. Nothing in it assumes you know
anything about software.

## Start here

## If something looks wrong

The version you are running is shown in small grey text at the top right of
every page, under the menu. If you ever need to report a problem, quote that —
it is the quickest way to tell whether you are seeing something already fixed.
